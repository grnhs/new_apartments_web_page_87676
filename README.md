## Загрузка через браузер

1. Распакуйте архив.
2. Откройте репозиторий `new_apartments_web_page_87676` на GitHub, ветку `main`.
3. Нажмите **Add file → Upload files**.
4. Перетащите ВСЁ СОДЕРЖИМОЕ распакованного архива: `index.html`, папки `assets` и `textures`, файлы лицензий, README и `.nojekyll`.
5. Важно: `index.html` должен находиться непосредственно в корне репозитория. Не загружайте ZIP и не создавайте вокруг файлов дополнительную папку `dist` или `apartment-3d`.
6. Нажмите **Commit changes**.
7. Если `.nojekyll` не виден или не загрузился, создайте его через **Add file → Create new file**: имя `.nojekyll`, содержимое можно оставить пустым или написать `# Static site`, затем Commit changes.

## Включение публикации

1. **Settings → Pages**.
2. **Build and deployment → Source → Deploy from a branch**.
3. **Branch → main**, папка **/(root)**, нажмите **Save**.
4. Дождитесь завершения публикации. Точная ссылка появится в Settings → Pages. Обычно это `https://ВАШ_ЛОГИН.github.io/new_apartments_web_page_87676/`.
5. Если вы ранее выбрали Source = GitHub Actions, переключите его на Deploy from a branch для этого архива. Пользовательский workflow сборки здесь не требуется: файлы уже собраны.

Файлы `index.html`, `assets/` и `textures/` должны остаться рядом. Их относительные пути поддерживают подпапку репозитория. Все текстуры локальные, CDN и API-ключей нет. Исходные чертежи, фотографии, служебные данные Beacon и ключи в пакет не входят.
